# Web Security Audit – Portfolio projekt

## O projektu

Tento projekt představuje simulovaný bezpečnostní audit webové aplikace malé firmy (rezervační systém pro kadeřnictví).

Cílem projektu je ukázat základní dovednosti v oblasti:
- IT audit
- kybernetická bezpečnost
- analýza rizik
- bezpečnostní dokumentace

## Co projekt obsahuje

- auditní zprávu (`audit-report.md`)
- registr rizik (`risk-register.md`)
- bezpečnostní checklist (`checklist.md`)
- poznámky k auditu (`evidence/notes.md`)

## Oblasti auditu

- Přihlašování a hesla
- Přístupová práva
- Validace formulářů
- Logování a monitoring
- Ochrana dat (HTTPS)
- Zálohování
- GDPR a práce s osobními údaji

## Použité principy

- OWASP Top 10
- základní principy IT auditu
- risk-based přístup
- bezpečnostní best practices

## Cíl projektu

Cílem je ukázat schopnost:
- identifikovat bezpečnostní rizika
- přemýšlet jako IT auditor / security analytik
- navrhovat praktická bezpečnostní opatření

## Kariérní zaměření

Zajímám se o juniorní pozice v oblastech:
- IT audit
- kybernetická bezpečnost
- GRC / compliance
- SOC L1 / security analýza
